## Products

- **Tunispare** (https://tunispare.com), founder. Spare-parts marketplace and shop software for phone repairers in Tunisia: workshops find the part that fits, buy it from local suppliers with delivery, and run the shop (stock, till, repair tickets, invoices). AI search on a self-hosted Qwen model in French, Tunisian darija and English. Runs on k3s set up with Ansible, CI/CD with GitHub Actions, monitoring with Prometheus, Grafana and Loki. Live since October 2026. Stack: NestJS, Next.js, TypeScript, MySQL, Python.

- **Malltech**, client work as developer. Full e-commerce platform for the Tunisian market in three services: NestJS + MongoDB API, Next.js storefront, back-office. Docker, Caddy, GitHub Actions.
- **Achabs Vintage**, client work as developer. Online shop of a vintage clothing boutique, built with Laravel 11.
